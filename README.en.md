# Network Sentinel

[中文](README.md) | **English**

A macOS menu bar app for UniFi. It reads your UniFi gateway's system log with an API Key and alerts you about internet outages and security threats, using the same severity levels UniFi shows (Low, Medium, High, Very High).

> Status: in development. Nothing to download yet.

## Features

- **Menu bar**: a shield icon with a status dot (yellow for Medium/High in the last 24 hours, red for Very High or a line that is down, gray when the gateway cannot be reached). Click it for the gateway name, the state of WAN1/WAN2 and the latest events.
- **Notifications**: macOS notifications from a severity you choose, with events of the same kind merged within 10 minutes and a note when a line comes back.
- **Bark push**: the same notifications on your iPhone through [Bark](https://github.com/Finb/Bark), with an optional custom ringtone and self-hosted server.
- **Main window**: an overview with a 24-hour outage strip per line, a filterable log with paging and CSV export, notification settings and app settings.
- **Sleep aware**: after the Mac wakes up it catches up at once and sums up what happened.

## What it watches

| Event | UniFi log key |
|---|---|
| Internet Down | `NETWORK_WAN_FAILED_2` |
| Internet Restored | `NETWORK_WAN_RESTORED_2` |
| Multiple Internet Disconnections | `NETWORK_WAN_FAILED_MULTIPLE_TIMES_2` |
| Temporary Internet Disconnection | `NETWORK_WAN_FAILED_TEMPORARY_2` |
| Packet Loss Detected | `ISP_PACKET_LOSS_2` |
| High Latency Detected | `ISP_HIGH_LATENCY_2` |
| Threat Detected | category `SECURITY` |

Each one can be turned on or off. Client and device events are ignored.

## Requirements

- macOS 13 or later
- A UniFi gateway running UniFi Network (tested on Dream Machine Pro Max, UniFi OS 5.1.33)
- A UniFi API Key: in the UniFi web UI, open **Integrations** in the left sidebar and click **Create New API Key**

The UniFi API Key and the Bark Key are stored in the macOS Keychain only. The app trusts the gateway's self-signed certificate on the first connection test and accepts only that certificate afterwards.

## Build

```bash
brew install xcodegen
xcodegen generate
open NetworkSentinel.xcodeproj
```

From the command line:

```bash
xcodegen generate
xcodebuild -project NetworkSentinel.xcodeproj -scheme NetworkSentinel -configuration Debug -derivedDataPath build build
swift test --package-path SentinelCore
```

If Xcode is installed but `xcode-select` still points at the Command Line Tools, prefix the
commands with `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` instead of running
`sudo xcode-select`.

Core logic lives in the local Swift package `SentinelCore/`, so it can be tested without
building the app. The project file is generated by XcodeGen from `project.yml` and is not
committed.

### App icon

`NetworkSentinel/Assets.xcassets/AppIcon.appiconset` is generated from
`Design/Icons/AppIcon-Dark.svg`. Re-run this after changing the artwork:

```bash
./scripts/make-app-icon.sh
```

The script renders the SVG once at 1024x1024 and scales it with `sips` to every size macOS
asks for.
