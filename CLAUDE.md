# Network Sentinel

macOS menu bar app (for UniFi). Reads the UniFi gateway system log with an API Key and alerts on internet-outage and threat events. Swift + SwiftUI, project generated by XcodeGen (`project.yml`).

## Build

- Xcode is installed but not selected (`xcode-select` points at CommandLineTools). Prefix build commands with `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`, do not run `sudo xcode-select`.
- `xcodegen generate` regenerates `NetworkSentinel.xcodeproj` (not committed).
- Core logic lives in the Swift package `SentinelCore/`; test it with `swift test --package-path SentinelCore`.

## Rules

- Only the API Key is used to talk to the gateway (header `X-API-Key`). No username/password login, no WebSocket.
- The API Key lives in the Keychain only. Never write it to files, logs, UserDefaults or test fixtures.
- Test fixtures must be anonymized: no real IPs, MACs or device IDs.
- Version numbers have two parts: `0.1`, `0.2`, ... (`MARKETING_VERSION`), GitHub release tags `v0.1`, `v0.2`, ...
- Desktop widget is deferred. Keep the App Group and the status file in place so a widget can be added later without touching the app.
